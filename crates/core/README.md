# rea-core

The runtime for [rea](https://crates.io/crates/rea): the template language,
the alias file format, the slot format of patched stubs, and process
execution. It exists so the `rea` tool and its stub can share one
implementation; it isn't meant as a general-purpose library, and its API
may change with any rea release.
