# Example alias file. Create the aliases with: aliasmux patch aliases.txt
#
# One per line, `name = template`.
#
# {1}, {2}, ...  the alias's arguments, from the front
# {-1}           the last argument ({-2} the one before, ...)
# {@}, {@+}      every argument no {N}/{-N} uses (zero or more / at least one)
# {2..}, {..-1}  slices, stopping before the end: from the 2nd / all but the last
# | && || ;      pipes and sequencing, as in sh
#
# `aliasmux --help` has the full syntax.
#
# Quote with '...' or "..." as in sh; references still work inside "...".
# A single command with no references gets its arguments appended (like a
# shell alias). Otherwise the argument count must match exactly.

flif270 = flif -d {1} - | convert -rotate 270 - - | flif -E 14 - {1}.rot.flif && mv {1}.rot.flif {1}
mkvize = ffmpeg -i {1} -y -c:v copy -c:a copy {1}.mkv
ll = ls -la
